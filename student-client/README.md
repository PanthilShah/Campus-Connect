# CampusConnect – React Web Client
## Lab 4: Full-Stack Client & Database Integration
**Student**: Panthil Shah &bull; Dhirubhai Ambani University

### Quick Start
```bash
npm install
npm run dev
```
App will run on `http://localhost:5173`.

### Features
- **Full CRUD Support**: View all students, register new student, update record, delete student.
- **Client-Side Validation**: Field validation for names, emails, and semester numbers.
- **Error Mapping**: Handles HTTP 400 Bad Request, 404 Not Found, and network errors.
- **Dark / Light Mode**: Seamless theme switching with localStorage persistence.
- **Centralized API Config**: Base URL configured in `src/config/api.js`.
